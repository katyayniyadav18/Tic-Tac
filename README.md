🎮 Tic Tac Toe Game

A simple, interactive, and responsive Tic Tac Toe game built using HTML, CSS, and JavaScript.

This project was created to practice JavaScript game logic, DOM manipulation, event handling, and responsive web design.

🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty square.
3. The first player to get three matching symbols in a row wins.
4. The three symbols can be:
   - Horizontal
   - Vertical
   - Diagonal
5. If all squares are filled without a winner, the game ends in a draw.
6. Click New Game to play again.
